# OIBSIP – Data Analytics Projects

A collection of data analytics and machine learning projects completed as part of the Oasis Infobyte Internship Program.

### Projects

1. **Google Play Store Analysis**
   - Exploratory data analysis of Google Play Store applications
   - Ratings, installs, pricing, categories and user sentiment

2. **Customer Segmentation Analysis**
   - RFM-based customer behaviour analysis
   - K-Means clustering and customer segment profiling

3. **Cleaning Data**
   - Data quality assessment and cleaning of a messy dataset
   - Missing values, duplicates, standardization, outlier detection and data type correction

### 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook
